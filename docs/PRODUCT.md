# Product

## Register

product

## Platform

Windows desktop

## Users

首要用户是希望清理磁盘空间、但担心误删文件的普通 Windows 用户。他们会选择一个自己理解的目录，快速确认哪些文件内容完全相同，并在执行清理前清楚知道保留哪一份、回收哪些副本。专业用户可以使用同一流程，但不是界面密度和术语的主要依据。

## Product Purpose

“归简”是一款 Windows 重复文件整理工具。它扫描任意目录，通过文件内容而不是文件名判断完全重复文件，自动给出保留与回收建议，并在执行前重新核验后将副本移入系统回收站。成功意味着用户无需理解哈希、硬链接或文件系统细节，也能快速完成一次可核对、可反悔的整理。

## Positioning

它不是综合“垃圾清理器”，而是一件只做完全重复文件、以内容确定性和安全复核为核心的 Windows 工具。

## Brand Personality

冷静、精确、可信。表达直接，不炫技，不用营销口吻解释显而易见的界面；视觉和交互应像一件经过认真打磨的 Windows 桌面工具，熟悉但不粗糙。

## Anti-references

- 不做网页管理后台式的卡片仪表盘，也不把数字摘要、解释文字和安全提示重复铺满页面。
- 不使用大量圆角容器、阴影、渐变、玻璃效果、暖黄色装饰或吸引注意力但无任务价值的动效。
- 不使用左右两套相互竞争的滚动区域，也不出现细窄、悬空或与系统行为不一致的自定义滚动条。
- 不把控件、标题和留白整体放大来伪装“高级感”；默认密度必须适合桌面工具。
- 不依靠文件名相似度暗示重复；只有内容完全相同才进入重复组。

## Design Principles

1. **确定性优先。** 每个重复组都明确表达“内容相同”、默认保留项和预计可回收结果。
2. **任务优先。** 每个屏幕只突出当前一步需要完成的动作，避免重复摘要和解释。
3. **安全但不唠叨。** 用默认选择、最后一份保护、回收站和最终确认构成安全链路，不在每个区域重复警告。
4. **熟悉胜过新奇。** 使用 Windows 用户已经理解的列表、选择、按钮、焦点与资源管理器操作。
5. **紧凑但不拥挤。** 默认尺寸克制，通过对齐、分隔和层级承载信息，而不是大卡片、大字号或大面积留白。

## Accessibility & Inclusion

默认界面保持紧凑，并正确跟随 Windows 系统缩放，而不是主动放大全部控件。核心流程支持键盘操作、清晰焦点、减少动画以及非颜色单一线索；在 200% 系统缩放下允许结构性重排和减少同屏信息，但不能阻断选择、审阅和清理。
