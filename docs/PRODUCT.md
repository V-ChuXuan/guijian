# Product

## Register

product

## Platform

Windows desktop

## Users

首要用户是希望清理磁盘空间、但担心误删文件的普通 Windows 用户。他们会选择一个自己理解的目录，快速确认哪些文件内容完全相同，并在执行清理前清楚知道保留哪一份、回收哪些副本。专业用户可以使用同一流程，但不是界面密度和术语的主要依据。

## Product Purpose

“归简”是一款 Windows 重复文件整理工具。它扫描任意目录，通过文件内容而不是文件名判断完全重复文件，自动给出保留与回收建议，并在执行前重新核验后将副本移入系统回收站。成功意味着用户无需理解哈希、硬链接或文件系统细节，也能快速完成一次可核对、可反悔的整理。

## Positioning

它不是综合“垃圾清理器”，而是一件只做完全重复文件、以内容确定性和安全复核为核心的 Windows 工具。

## Brand Personality

冷静、精确、可信。表达直接，不炫技，不用营销口吻解释显而易见的界面；视觉和交互应像一件经过认真打磨的 Windows 桌面工具，熟悉但不粗糙。

## Anti-references

- 不做网页管理后台式的卡片仪表盘，也不把数字摘要、解释文字和安全提示重复铺满页面。
- 不使用大量圆角容器、阴影、渐变、玻璃效果、暖黄色装饰或吸引注意力但无任务价值的动效。
- 不使用左右两套相互竞争的滚动区域，也不出现细窄、悬空或与系统行为不一致的自定义滚动条。
- 不把控件、标题和留白整体放大来伪装“高级感”；默认密度必须适合桌面工具。
- 不依靠文件名相似度暗示重复；只有内容完全相同才进入重复组。

## Design Principles

1. **确定性优先。** 每个重复组都明确表达“内容相同”、默认保留项和预计可回收结果。
2. **任务优先。** 每个屏幕只突出当前一步需要完成的动作，避免重复摘要和解释。
3. **安全但不唠叨。** 用默认选择、最后一份保护、回收站和最终确认构成安全链路，不在每个区域重复警告。
4. **熟悉胜过新奇。** 使用 Windows 用户已经理解的列表、选择、按钮、焦点与资源管理器操作。
5. **紧凑但不拥挤。** 默认尺寸克制，通过对齐、分隔和层级承载信息，而不是大卡片、大字号或大面积留白。

## Review and Cleanup Contracts

- 扫描结果必须显示未完成检查的项目及原因；没有重复组时也不能隐藏这些诊断。诊断按需展开，每页最多50项，所有路径与原因均可翻页查看。
- 单文件清理只处理用户确认的路径，成功后更新当前结果，不重新扫描整个根目录。
- 清理成功或失败均保留其他重复组的人工选择；若回收的是原保留项，剩余副本中仍须保留至少一份。
- 清理结果逐项报告成功、变化、阻止和失败；原扫描计数表示扫描时的范围，不冒充重新检查后的统计。
- 有未处理文件时，结果默认展示这些文件的完整路径和原因，可复制路径或定位仍存在的文件；成功记录可另行查看。处理记录每页最多50项，筛选和数量基于完整报告，切换筛选回到首页。
- 部分完成后可以回到当前审阅会话检查未处理文件；不自动重扫，也不自动重试。
- 文件名和路径检索、待清理筛选只影响展示；清理内容仍覆盖当前会话的全部选择，必须明确这一范围。恢复全部建议前先确认，避免覆盖人工选择。
- 大结果集每页最多显示50个重复组，展开的每组每页最多显示50个文件。翻页只改变展示，完整会话的人工选择和清理总数保持不变；整组保留仍作用完整组，全部展开/收起仍作用完整会话。
- 搜索和待清理筛选检查完整会话，筛选变化回到第一组页。搜索命中组内后面的文件时先显示首个匹配文件所在页，随后可手动翻文件页；结果缩短时调整到有效页。
- 组与文件分页标明范围并支持键盘，翻页后焦点可继续操作；不新增第二滚动区。
- 整组全部保留一次完成；同名文件的选择与操作控件需要关联路径描述。
- 存在人工选择修改时，重新扫描和更换文件夹先确认；取消保留当前会话。没有人工修改时直接执行。
- 单文件最终确认完整呈现相对路径，允许换行和键盘读取，不依赖鼠标悬停。
- 行菜单执行复制路径或定位文件后，将键盘焦点返回该行的菜单触发器。
- 审阅和清理确认提前标出已知的长路径限制；批量确认统计完整会话中已选的受限文件，并说明预计容量仍包含这些文件。提示不自动改选，也不替代后端最终复核；没有提示不代表文件一定能回收。

## Cleanup Feedback and Stop

清理显示已处理数量、总数量、当前文件以及成功、跳过和失败计数。停止请求会在当前文件完整处理后生效；等待期间明确说明这一边界，不能把请求成功显示为清理已经停止。

停止后保留实际完成报告和剩余选择，显示尚未开始的数量并允许返回审阅。已回收文件仍在系统回收站，不因停止自动还原；再次清理仍需用户确认。

扫描或清理运行时关闭原生窗口会被拦截，并提示先停止操作后再关闭；关闭请求不自动取消或退出。等待结果返回后，窗口可正常关闭，避免处理中退出而丢失本次报告。

清理命令异常表示未能确认结果，不能据此宣称“清理没有开始”。保留具体错误并提示检查文件状态，不自动重试，也不将已确认的逐项失败报告混为未知结果。

单文件入口也区分可信逐项失败、明确前置拒绝和未知结果。未知结果弹窗保留原错误、提示先检查文件状态，仅提供返回检查，不直接再次回收同一目标；关闭后保留人工选择，不自动重扫。新目标重置局部提示，键盘焦点保持可用。

## Scan Feedback

枚举阶段使用不定进度，未知总数时不显示百分比。局部和完整内容比对分别显示本阶段完成量，不能冒充全流程百分比。发现文件数和文件容量表示枚举到的文件范围，不代表实际读取的字节量；当前路径可变化，读屏播报以阶段转换为主。

停止扫描请求失败只提示请求错误，继续等待原扫描结果，不把它当作扫描本身失败，也不提前开放重试或更换位置。进度订阅失败独立显示“进度暂不可用”，仍等待真实扫描结果；不能用静止的零计数冒充正常进度。

## Accessibility & Inclusion

默认界面保持紧凑，并正确跟随 Windows 系统缩放，而不是主动放大全部控件。核心流程支持键盘操作、清晰焦点、减少动画以及非颜色单一线索；在 200% 系统缩放下允许结构性重排和减少同屏信息，但不能阻断选择、审阅和清理。
